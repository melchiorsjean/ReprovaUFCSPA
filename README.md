# 📚 ReprovaUFCSPA

**Calculadora de notas para o sistema de avaliação da UFCSPA**

Descubra sua média, sua situação e quanto precisa tirar no exame, direto do celular.

### [🔗 Abrir a calculadora](https://melchiorsjean.github.io/ReprovaUFCSPA/)

</div>

---

## ✨ Funcionalidades

- 📱 **Feita para o celular**: tudo em uma tela, sem rolagem
- ⚖️ **Peso ou porcentagem**: escolha como informar o peso de cada nota
- ➕ **Notas flexíveis**: comece com 3 e adicione ou remova quantas quiser
- ⚠️ **Avisos úteis**: porcentagens que não fecham 100%, notas inválidas ou faltando
- 🎯 **Nota do exame**: calcula exatamente quanto você precisa tirar
- 🌙 **Modo escuro** automático

## 📐 Regras

| Média do semestre | Situação |
| :---: | :---: |
| **≥ 7,0** | ✅ Aprovado |
| **4,0 a 6,9** | 📝 Em exame |
| **< 4,0** | ❌ Reprovado |

No exame, a média final é composta por **60% da média do semestre** e **40% da nota do exame**, e precisa ser **6,0** para aprovação:

```
nota do exame = (6 − 0,6 × média) / 0,4
```

> Ex.: com média **5,0**, você precisa de **7,5** no exame.

## 🛠️ Tecnologia

Um único `index.html` com HTML, CSS e JavaScript puros. Sem dependências, sem back end, hospedado no **GitHub Pages**.
